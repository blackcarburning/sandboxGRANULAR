MyGrain CEF FX 0.1.0

The MYGRAIN FX stereo effect, with the full Chromium Embedded Framework runtime inside its plugin bundle. The full MYGRAIN app opens in the plugin window. No separate Chrome installation or connection code.

Windows x64 · CEF FX 0.1.0macOS 13+ · CEF FX 0.1.0 · Apple Silicon + Intel

A separate plugin: MyGrain CEF FX. Existing MYGRAIN FX 0.4.0, Bridge 0.8.0 and MyGrain CEF instrument remain unchanged.

Install

  1. Close the DAW fully and extract the ZIP. Keep the entire plugin folder, including Chromium resources and helpers.
  2. Windows: copy MyGrain CEF FX.vst3 into C:\Program Files\Common Files\VST3\.
    Mac: from the extracted folder run bash "Install MyGrain CEF FX.command". The checksum/signature-verified installer backs up only this plugin and installs it in your user VST3 folder. The universal Mac build is ad-hoc signed, not Developer-ID signed/notarized.
  3. Rescan VST3, then insert MyGrain CEF FX as a stereo effect on an audio track — not as an instrument.

Process your track

  1. Open the plugin and sign in. Press Start MYGRAIN if requested. The hosted app requires internet.
  2. Open DAW INPUT. Choose Filters, Master, Final stage or Direct. Use its gain, input mute, dry/wet and the existing effect cards, Cooking Pot and Master Baker.
  3. Press Arm FX or native Arm, enable track processing/monitoring, and play the DAW. Enabled patch sources run silently for modulation while armed; their audio is not mixed into the return.

Same FX timing: fixed 1,000 ms latency, reported to the DAW for compensation. Stop, bypass, disconnect, missing returns and offline bounce use delayed dry. To capture effects, print/render in real time. This is not a low-latency monitoring plugin. Never feed its return into its own input.

Project storage and app updates

Auto-save defaults On, checking every 60 seconds (adjustable 15–3600). Store now embeds the editable patch, required sources and FX input settings; native Arm/bypass/dry-wet are retained too. Save the DAW project normally to write the last completed snapshot to disk. No account password or session token is stored in the project.

Closing the editor keeps the embedded engine and auto-store running. Reopen resumes it. Store + reload app first stores the FX patch, then refreshes/reconnects and restores it; a failed or busy store cancels the reload. Reload interrupts live processing. New instances load the current hosted app. Native preview audio and filename/confirmation dialogs are retained.

Preview scope

Stereo input/output, 8–192 kHz, float32/float64, standard automated host bypass. No new browser-effect automation or sidechain. Native Windows and Apple Silicon runner results are included in VERIFICATION.txt. Physical DAWs/devices, native Intel runtime, multi-instance performance and international IME remain unverified.
