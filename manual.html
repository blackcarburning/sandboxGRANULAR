MYGRAIN Manual

MYGRAIN is a keyboard-first granular instrument built around one shared BPM clock, multiple sample-backed layers, live waveform editors, Bastardloops, drums, internal effects, and fast iPhone performance controls.

Start HereTap Start, set BPM, generate or load a source, then play the keyboard.
Main SoundGranular layers read from generated, mic, sample, and output-captured waveforms.
Loop LayersBastardloops A/B/C/V/P/O, sample layer, and drums can run beside the keyboard.
SafetyUse Panic, Reset Engine, Debug Console, and the manual links when testing builds.

Quick Start

  1. Tap START MYGRAIN to unlock browser audio.
  2. Set BPM. This is the shared clock for loops, grains, sequencer timing, and internal LFOs.
  3. Create sound with Generate Source, Record Mic, Load Audio, grain sample browsers, Bastardloops, or the drum machine.
  4. Play the on-screen keyboard. Use Hold for drones and Arp for stepped held-note playback.
  5. Use the right-edge Jump handle on iPhone to move between sections without scrolling through the whole app.
  6. Use Panic if anything sticks, then use the Debug Console if you need to send a report.

Mental Model

Think of MYGRAIN as one performance mixer. Different layers create or load audio, the keyboard and transports decide when to play it, and the filter/effects/output chain shapes the final sound.

Signal Flow

Most sound eventually reaches the pre-filter bus, then the filter/effects/output path.

Sources and Waveforms

Sources are audio buffers MYGRAIN can read from. They stay separate so a generated loop, mic recording, loaded sample, grain sample, and output capture do not overwrite each other unexpectedly.

Generated LoopCreated inside the app, BPM-aware, and usable for dry playback or granular playback.
Mic RecordingCaptured from the browser microphone and normalized for centered granular playback.
Loaded AudioAny audio file you load from the device, then trim with loop start/end.
Grain SamplesMain, A, and B sample slots selected from source browsers.
Output SourceA capture of MYGRAIN itself, useful for resampling back into the grain engine.
Waveform TuneSource tune controls act on the source playback path, not just the picture.

Granular Layers

The grain engine has three visible performance layers: Main, A, and B. Each layer has source choice, grain position, size, volume, tuning, width, smoothing, and envelope controls.

  • Quick Grain exposes the controls most likely to matter while playing.
  • Grain jumps to the fuller grain controls.
  • Main Wave, A Wave, and B Wave jump directly to waveform editors.
  • Smooth/cloud-style grain settings are better for pads and held notes; shorter rhythmic settings are better for choppy or percussive playback.

Bastardloops

Bastardloops are generated loop layers that share a transport. They are useful for quickly building a backing bed around the playable granular keyboard.

LayerSource familyNotes
ASAMPLEDROPFirst generated Bastardloop layer.
BSAMPLEDROP_2Second layer with reverse, pitch, level, and filter controls.
CSPLICE_CLAWThird layer with the same independent controls.
VSAMPLES_VOCALVocal layer with octave, semitone, and fine-tune controls.
PSAMPLES_PIANOPiano layer with octave, semitone, and fine-tune controls.
OSAMPLES_ORCHOrchestral layer with octave, semitone, and fine-tune controls.

Don't Preserve Duration switches a layer into sampler-style pitch mode. Off means pitch changes preserve bar length; on means pitch and speed move together.

Drum Machine

The drum machine loads kick, snare, and hat sources, then places them on a 16-step grid. Random Drums loads samples and creates a pattern; Random Samples only changes the samples.

  • Drum randomization forces the drum machine layer to 100%.
  • Bastardloop random levels are capped so drums remain audible.
  • Kick, snare, and hats have level, decay, length, and pitch/tune controls in the drum popup.

Keyboard, Hold, and Arp

The keyboard is the main instrument surface. Touching a key starts granular and oscillator playback through the current patch.

ControlMeaning
HoldHeld notes keep sounding after release.
ArpSteps through held notes using the shared BPM clock.
OctaveMoves the keyboard note range without changing generated-loop transpose.
PanicStops notes, stuck voices, and transport problems.

Mixer and Layer Switches

The mixer controls how much each layer contributes. The Layer Switch panel lets you mute or re-enable layers quickly while performing.

If something disappears after randomization, check Layer Switches first, then check the Mixer level for that layer.

Filters and Modulation

Low-pass and high-pass filters shape the main path. LFO route buttons attach modulation to filter, grain, source, and effects targets. LFOs are BPM-aware so a tempo change keeps the musical ratio stable.

  • LP/HP cutoff sets tonal range.
  • LP/HP resonance emphasizes frequencies around the cutoff.
  • L1/L2/L3 route buttons assign internal LFOs to parameters.
  • INV flips modulation direction for the selected route.
  • All LFOs Square forces square internal LFO movement until cleared.

Internal Effects

Internal Effects contains the final chain and the FX-muted path. Effects are bounded to avoid runaway feedback, but high wet/depth settings can still be dramatic.

Effect familyUse
Delay/ReverbSpace, repeats, and ambience.
Drive/Crush/FoldHarmonic damage and texture.
Ring/Pan/LFO placementMotion, stereo animation, and placement shifts.
FX MuteHard-mutes the wet path without moving the slider positions.

Recording and Export

  • Record Output captures the live mix.
  • Rec Output Source records MYGRAIN back into the output source waveform so it can be granularized again.
  • Export renders DAW-ready audio from the current BPM and bar count.
  • WAV Repository stores takes and exported audio for later download or review.
  • Export Patch saves settings; it does not embed every audio buffer.

Randomize and Reset

Randomise Patch changes the current patch while protecting important performance controls. Mega Random goes wider: it can regenerate/load multiple layers, drums, source states, and internal modulation.

Reset Patch returns controls to the app defaults. Reset Engine rebuilds the audio graph when the browser gets into a bad audio state.

iPhone Navigation

The iPhone layout is intentionally dense. Use these shortcuts:

  • Use the right-side Jump tab to go directly to Keys, loops, Drums, Layer Switch, Mixer, Quick Grain, Waveforms, FX, and Pan Lab.
  • The drawer retracts after the target section is reached.
  • The top manual button opens this page from the start of the app.
  • The lower manual card appears above the Debug Console so help is still available after scrolling.

Debug Console

The Debug Console is for reporting app state. If MYGRAIN falls over, tap Copy Debug and paste the text back into chat. Use Clear Log only after saving anything important.

Troubleshooting

ProblemTry this
No soundTap Start MYGRAIN, check Layer Switches, check Mixer levels, then use Panic and Reset Engine.
A layer is too loud or quietOpen Mixer, then check the matching Bastardloop/drum/grain level.
Pitch feels wrongCheck keyboard octave, generated-loop transpose, source waveform tune, and V/P/O semitone/fine controls separately.
Loop points are strangeJump to Waveforms and inspect start/end handles for the active source.
iPhone is showing an old buildReload the public route, check the visible build badge, and remove/recreate stale home-screen shortcuts if needed.
Something is stuckUse Panic. If it continues, use Reset Engine and copy Debug Console output.

Working habit: when tuning, change one layer at a time. Solo the layer, tune it, then bring the rest of the mix back in.
