MYGRAIN Manual

A practical operator manual for MYGRAIN: make sounds and beats, record and organise vocals, shape sample loops, then arrange saved patterns into a repeatable song. Each workflow explains both the controls and why they work that way.

Manual revision: 2026-10-14. Includes Song mode, the global M vocal library, V Loop Cut and Section Repeat, Pan Lab reset, and the backing-vocal M+ workflow.

Start Sound FastTap Start, set BPM, generate or load a source, then use the keyboard, loops, drums, or Bastardloops.
One ClockBPM drives the arpeggiator, sequencers, Bastardloops, drums, LFOs, delay divisions, and exports.
Layered MixerGranular, oscillator, generated loop, Dropbox sample, drums, and Bastardloops can all run together.
Three Kinds of SaveVocal versions keep raw takes globally; song parts keep complete editable patterns; patch ZIPs provide portable restore points.

Quick Start

  1. Tap START MYGRAIN. Browser audio is locked until this gesture; microphone permission is only requested when you use Record Mic.
  2. Set BPM and Pattern Length. BPM controls musical timing across the app; Pattern Length controls sequencer-style grids.
  3. Create or load sound with Generate Source, Low Noise Source, Record Mic, Load Demo, Load Audio, grain sample browsers, Bastardloops, Dropbox Sample Layer, or the Drum Machine.
  4. Play from Keys. Use Hold for drones, Arp for clocked held-note playback, and Octave to move the keyboard range.
  5. Build rhythm or texture with Generate Loop, Start Bastardloops, Start Drums, or Dropbox Sample Layer.
  6. Balance layers in Layer Switches and Mixer. If a layer is silent, check both its switch and its level.
  7. Use Export WAV, Export Final Mix to Repo, Export Stems, or Export Patch ZIP when the patch is worth keeping.
  8. For vocals, record into M, save versions in the Vocal Take Browser, and use M+ for an independent backing take. For an arrangement, save New Parts in Song, then Arm Cache and Play Song.
Mobile habit: on iPhone, use the right-side Jump drawer instead of long scrolling. It goes directly to Keys, loops, Drums, Layer Switch, Mixer, Quick Grain, Actions, Export, WAV Browser, Stem Export, Grain, Mix, LFO, FX, Sources, Waveforms, and Pan Lab.

What MYGRAIN Is

MYGRAIN is best understood as a performance mixer wrapped around several sound makers. The playable center is a three-layer granular instrument plus oscillator. Around that are generated loops, one-shot sample sequencers, Dropbox sample playback, a drum machine, filters, shared effects, recording, and repository export tools.

Signal Flow

Sources feed instruments and loop layers; the mixer feeds the filter/effects/output path.

Performance Order

The app is arranged so performance controls appear before deep editors.

Navigation and Layout

The app has three main ways around: normal scrolling, the right-edge Jump drawer, and direct buttons that open popups such as Synth, Drum Machine, Patch Browser, WAV Browser, Stem Browser, and sample browsers.

Starting and Audio Safety

Browsers require a user gesture before sound can start. START MYGRAIN creates or resumes the Web Audio engine, unlocks the audio graph, and shows the app.

  • Start MYGRAIN unlocks audio. If a button says to start first, tap this before retrying.
  • Panic stops held voices, stuck notes, and active transport state without resetting the patch.
  • Reset Engine rebuilds the audio graph when browser audio is in a bad state.
  • Stop All stops active app transports; Restart All restarts tracked clocked layers together.
  • Microphone access is separate. MYGRAIN does not ask for the mic until Record Mic is used.

BPM, Pattern Length, and Timing

Set BPM is the shared musical clock. It affects generated loop timing, arpeggiator rate, sequencer grids, Bastardloop transport, Drum Machine transport, LFO multipliers, delay divisions, and render/export timing.

Pattern LengthSets the length for step-based pattern work. The visible default is 16 steps, with longer patterns available.
Export BarsSets the render length for WAV export. This is separate from Pattern Length.
Restart AllUse after timing changes when you want active loop layers to realign from a fresh origin.

Granular Layers

The granular instrument has three performance layers: Main Grain, Grain A, and Grain B. Each can use different source material and tuning while sharing the app-wide mixer and FX chain.

Main GrainBase playable layer. Commonly use it for the central sample or mic recording.
Grain ASecondary layer. Good for a higher interval, alternate source, or wider texture.
Grain BThird layer. Good for bass, octave support, or a contrasting grain size.

Important controls include Source, Start Point, Grain Size, Coarse Tune, Fine Tune, Attack, Decay, Release, Blend, Smoothing, Stereo Width, Volume, and Solo. The Quick Grain card brings the most-used tuning, width, smoothing, and LFO depth controls into the performance area.

Generated Loop and Dry Loop

Generate Loop creates a BPM-aware loop that can run as its own dry layer and also feed the grain engine. Loop Play and Loop Stop control that loop transport. Loop Level, Dry Trim, and the Loop On layer switch control how much of it reaches the mix.

Unity trim defaults: Dry Trim, Filter In and Filter Out start at 0.0 dB when starting MYGRAIN, loading a preset, resetting or using Randomize, Mega or Sparse. Filter gain modulation is cleared and Auto Makeup starts off so those filter trims really give unity gain rather than an automatic cut or boost. You can adjust them or enable Auto Makeup manually afterwards. Exact saved Song-part recall retains its own settings.

  • Gen Swing changes generated-loop timing feel.
  • Loop Transpose transposes generated-loop playback by octaves.
  • Gen Loop Mix controls the generated-loop contribution.
  • Dry Filter Off bypasses or enables filter treatment for the dry loop path.

Loop L and Loop X Sequencers

Bastardloop L plays one-shot leads from SAMPLES_LEADS. Bastardloop X plays one-shot bass samples from SAMPLES_BASS. They are not random sliced loops like A/B/C/V/P/O; they are synced note sequencers.

X Filter Accent: accented steps change the filter envelope, not the voice volume. The signed Filter Accent slider adds or subtracts up to 50 percentage points from Filter Env, clamped to 0–100%; zero leaves the normal envelope unchanged. Use X's level slider for volume. Existing accent settings still load. A filter sweep can naturally change perceived loudness as it passes or removes frequencies.

V: Vocal Loops and Loop Cut Editor

V makes a sample-backed vocal loop from SAMPLES_VOCAL. Generate or browse a loop, balance its level, tune it, and use reverse or shift when needed. This is distinct from M: V assembles existing vocal samples; M records your own performance.

  1. Load or generate V material. Start Bastardloops to hear it against the other enabled layers.
  2. Open Loop Cut. The waveform represents the full existing loop. Drag Start and End, use the time fields, or adjust the focused handle with keyboard arrows.
  3. Choose Snap for a musical grid, from fine divisions through a bar, or disable snap for free placement.
  4. With the cut enabled and Section Repeat Off, only the selected region sounds. Everything outside it is silent, but the complete loop still occupies its original duration.
  5. Switch Section Repeat On to tile the marked section from its Start position to the end of the full loop. The final copy is shortened to fit. Any time before Start stays silent.
  6. Use Vocal + Metronome to hear V alone with a timing reference, or With Bastardloops to audition it with the enabled loop layers. Both start at the full loop origin, not at the selected Start handle. Stop or close the editor to end this audition.
  7. Full Loop removes the cut/repeat and returns to the full vocal loop. The original source audio has not been destroyed.
Leave room for your singerMark a short V response near the end of a bar. Leave Section Repeat off. The rest of V is silent, so M can carry the lead phrase without changing the beat length.
Turn a fragment into a hookOn a 16-step loop, mark a five-step section starting at zero and enable Section Repeat. The result is 5 + 5 + 5 + 1, not a 20-step loop. If Start is later, the opening remains silent and only the remaining duration is filled.

Why it works this way: cropping the timeline would shorten V and move later material off the shared clock. The editor instead gates or repeats audio inside a full-length playback buffer, with short edge fades. Original PCM, loop duration, tempo and shift remain available. Song parts store the editor settings with the source; cached song audio and song WAV exports use that saved edit, not whichever window you change later.

M and M+: Recording and the Global Vocal Library

M is the dark-green MAIN VOCAL card, a microphone loop for your lead vocal. M+ is the dark-orange BACKING VOCAL card, an independent microphone loop for backing vocals: its own take, record level, tuning, filter, dedicated effects, volume, left/right pan and layer switch. Both cards use dark-grey buttons with blue text. Both use the Bastardloops clock and the same global Vocal Take Browser; opening it from a lane makes that lane the load/save target.

M+ Pan Left / Right: zero is Centre; negative values place the backing vocal left and positive values place it right. Use Centre Pan to reset just this lane's placement. Pan moves the complete M+ output, including its dedicated delay, chorus and room reverb, without moving the lead in M. It is saved with patches and song parts and retained during Mega/Sparse randomisation. Older parts and patches without pan load centred. The raw take in the global vocal library is unchanged. This is a static mix placement control, not Pan Lab's animated processing.

Record a Take

  1. Start MYGRAIN and set BPM and Pattern Length before recording. Set Record Length to 1–8 loops. A loop follows the current pattern duration, not an arbitrary number of seconds.
  2. Choose Record Mic for the lane's recording workflow, or Record + Loop to bring in the enabled performance backing at the recording start after the count-in. Allow microphone access when asked.
  3. Listen to the one-bar, four-beat count-in; start singing at the recording start. Watch Record VU and adjust Record Level. Input level is separate from playback volume. Prefer headphones so the backing is not recorded back through the microphone.
  4. The selected duration is captured and the take is made available as a tempo-linked loop. Longer recordings can span several repeated pattern cycles. Use Start Bastardloops, the lane switch and Mixer to hear it.
  5. Adjust playback level, semitone/fine tune, Preserve Duration, reverse and filter. Add the lane's dedicated delay, chorus, room reverb or compressor only as needed. These are playback treatments, not a replacement for a clean recording.
  6. Use Save Version before recording over a take you want to keep. Normalize changes the working take's gain; it cannot repair clipping. Clear removes that lane's working take, not its previously saved library versions.

Save, Browse and Organise

Replacing a performance: Record + Loop plays the enabled loop layers, which can include an older take already in the recording lane. Save Version, then Clear that working lane before recording an alternative if you do not want the old performance in your backing. Clearing M+ leaves the loaded lead in M intact, and both lanes' saved library versions remain available.

Vocal Recording Examples

Build a lead from several takesAt 120 BPM with a 16-step pattern, one loop is four beats, or two seconds. Set Record Length to 4 for an eight-second phrase. Record + Loop against your backing; Save Version as “Verse lead 01” under your user. Record again and save “Verse lead 02”. Audition both in the browser, then load the preferred take into M. Save a New Part to keep that choice and its mix.
Add a real double or harmonyKeep the chosen lead in M. Open M+, choose the same record length and Record + Loop to sing a separate double or harmony against it. Save this version in a “Backing vocals” folder. Keep the backing quieter than the lead; adjust fine tune and effects independently, then try Pan at 30% Left or Right to separate it from the lead. Save a song part with both lanes enabled to keep that placement. An independent performance usually gives a more useful double than loading the exact same PCM into both lanes.
Re-use a vocalist across songsSave useful takes under the vocalist's label. Open another song, open the browser from M or M+, select that vocalist and load a take. Rebalance and check tempo/pitch before creating a part. The original library take stays available to the first song and every other song.
Use a long take deliberatelyA four-loop M take can run across repeated cycles during live Bastardloops playback. Song mode freezes only one pattern per part and repeats that capture. To preserve a complete longer phrase in ordered playback, choose a pattern duration long enough to contain it before recording and saving the part. Increasing the part's Repeats does not make the frozen cache advance through a longer raw vocal.

For an evolving vocal session, name versions by role and number, keep lead and backing folders, and save before changing the working take. For a committed arrangement, Recall the part, load the chosen versions into M/M+, adjust their mix, then Amend and Save Amendment. Editing a library version's name or location does not retroactively change an already saved song part.

Song Mode: Arrangement, Recall and Cache

Song mode turns complete MYGRAIN patterns into an ordered arrangement. A part is not just a preset name or a MIDI pattern: it is a saved, editable snapshot of sounds, sequences, keyboard notes, mutes, levels, effects, tempo and pattern length, including the loaded vocal takes and V editor settings. The global vocal library remains outside that snapshot.

First Song: Verse, Chorus, Verse

  1. Use the green Song quick tab or Jump to reach the Song card. Enter a name and select New Song.
  2. Build your verse live, load/record its vocals, enter a part name and repeat count, then choose New Part. Wait for a successful save. This stores the whole current pattern independently of future live edits.
  3. Change the live patch for a chorus and save another New Part. Expand Verse and choose Reuse Part for a second verse occurrence; use its arrows to put it after Chorus.
  4. Set each occurrence's Repeats, for example Verse × 4, Chorus × 8, Verse × 4. Repeat counts are whole patterns, not beats or seconds. Give parts colours if helpful.
  5. Select Arm Cache. Wait for every needed unique part to be ready, then choose Play Song. Playback follows the displayed order and saved repeat counts, ending after the final part unless a looping mode is selected.
  6. Use Export Song to WAV Folder for the same arranged audio. Use Stop Song to stop automatic playback and cancel pending preparation.

Why Song Mode Uses Frozen Patterns

The live instrument is intentionally dynamic. Grain voices, random slices, filters, modulation and effect tails change over time. Rebuilding those engines at every transition depends on JavaScript, decoding and UI work; that is the wrong place to decide the instant the next beat starts.

Arm Cache separates preparation from performance. Missing parts are rendered as one-pattern final mixes in a muted, isolated MYGRAIN engine, without replacing the live patch. The editable snapshot and source audio remain saved separately. Playback schedules the resulting WAV patterns on the audio clock: the old part stops at the same sample boundary where the next starts. UI highlights follow playback, but do not drive timing.

Pattern duration is the contract. One step is a sixteenth note: duration = steps × 60 ÷ BPM ÷ 4. At 120 BPM, 16 steps take two seconds; four repeats take eight seconds. Each part uses its own saved tempo and length. Long samples and reverb tails cannot stretch a part past its arranged boundary; they are cut at that boundary. The frozen pattern is repeated, not the live engine rerun. Random/LFO movement is the movement captured during preparation.

Reuse avoids unnecessary work. One verse reused ten times needs one source snapshot and one frozen render, not ten copies. Identical amendments, renames, order changes and repeat changes reuse unchanged renders. Actual sound/settings amendments invalidate only the changed source; reused occurrences then share the amended sound. This makes arrangements quicker to prepare and limits storage/memory growth.

Cache, Persistence and Practical Limits

  • First preparation takes real time: at least one pattern's capture for each uncached part. The default is two simultaneous preparations. Cache preparation offers 1–10 workers; one is safer on slower devices. Ten is experimental, not guaranteed faster.
  • Heavy concurrent renders can cause gaps or crackles that become part of frozen audio. Lower the worker count before preparing. Changing the count does not rewrite an already saved render; it only affects future preparation.
  • Ready/pending counts and per-part Ready, Saved, New or Changed statuses show what remains. Expand Notes and Instructions for the detailed cache summary.
  • The server holds the authoritative parts and frozen audio. Browser storage caches integrity-checked copies across reloads. Unavailable/full browser storage falls back to server reads with a warning; it does not discard the saved part.
  • Portable recall: parts save their controls, modulation routing, patterns, held keys and all available grain, microphone, raw/rendered vocal and drum audio. Empty source slots remain empty; recall does not substitute a phone's previous samples. Parameter capture/recall does not need localStorage as scratch space, and frozen playback uses the verified server WAV rather than the phone's live mixer/effects.
  • After the PortableFreeze update: reload once and use Arm Cache. Older affected renders refresh once from their saved settings and audio; source archives stay unchanged. Missing information in an old snapshot cannot be recreated. A refreshed freeze may capture a new random variation, then other devices reuse that same saved WAV.
  • Another phone needs the same song library access. The library key is a device-local credential, not a sound setting. A different key opens a different library. Do not clear site data when updating.
  • Small arrangements can be scheduled fully ahead. Larger ones load one part ahead and keep a bounded decoded-audio cache. If storage cannot meet a playback deadline, playback reports an error rather than silently omitting a part or moving the beat.
  • Keep the page visible during preparation. Stop Song, Stop All and Panic cancel playback/preparation. Save or cancel any pending amendment before playing an arrangement.
  • Song WAV export uses the stored renders in occurrence order and repeats. The existing 64 MB WAV-upload limit still applies; very long arrangements may need shorter exports or a DAW workflow.
Live versus Song: changing live effects while a frozen song plays does not remix its saved WAV. Recall and amend the part, then re-arm. For complete vocal phrases, make the saved pattern long enough; for freely evolving improvisation, use live Bastardloops/Audition rather than expecting frozen song repeats to vary.

Dropbox Sample Layer

The Dropbox Sample Layer loads one sample from SAMPLEDROP, SAMPLEDROP_2, or SPLICE_CLAW and plays it as its own loop layer.

  • Browse Samples opens the browser for manual choice.
  • Load Random Sample picks a random sample from the selected source family.
  • Stretch To Loop stretches the sample to fit the Bastardloop bar. Off means the sample is dropped at the start of each bar.
  • Dropbox Semitone and Dropbox Fine Tune tune playback.
  • Preserve Duration keeps length stable while tuning. Turn it off for classic sampler speed/pitch behavior.
  • Solo Off/On isolates the Dropbox sample layer for checking.
  • Dropbox Sample On/Off in Layer Switches mutes or enables this layer without changing its settings.

Drum Machine

The Drum Machine has six independent lanes: kick, snare, hi-hat, percussion, clap and cymbals, with sample browsing, steps, ratchets, pitch, level, decay and length controls in the popup. Clap uses the local SAMPLES_CLAP collection. Cymbals uses SAMPLES_CRASH: the lane can also play rides and open hats stored in that collection; it is not limited by the sample's filename.

Kick, snare, hat, clap and crash sample browsers use their fixed folders without showing a folder chooser. Perc keeps its Sample Folder chooser so you can browse other collections. Use Search Samples to filter the current folder.

The orange playhead follows the current step in all six lanes, including clap and crash. Compact action buttons leave more space for the grids. The popup's Kick, Snare, Hat, Perc, Clap and Crash tabs jump directly to each lane without closing the drum machine.

Hat and Crash accents: toggle the small Accent button above any step, then adjust that lane's Accent Amount. Crash accents are independent of the hat pattern; use them for ride emphasis or open-hat pulses. Set Accent Amount to zero for no added level emphasis.

48 dB/oct low-pass: Hat and Crash each have an independent Filter Cutoff and Accent Filter Env. Cutoff runs logarithmically from 20 Hz to 20 kHz; 100% with no envelope bypasses the filter. On accented hits only, the envelope briefly opens the filter and decays back to the cutoff over the hit. The envelope amount is independent of the level accent amount. These settings save with patches, reloads and song parts; older saves load with the filters open and no new crash accents.

Pan Lab and Reset Pan Lab

Pan Lab is a creative stereo-motion processor: centre/width, tempo-linked LFO motion, audio-driven movement, orbit and gravity can make a patch wander dramatically. That can be useful for a transition or texture, but continuous strong movement is not a neutral mix setting. In a finished song it can make vocals and drums feel unstable or less clear, and exaggerate a sense of poor sound quality. Use it deliberately, not simply because randomisation switched it on.

  1. Use Actions → Reset Pan Lab to disable Pan Lab motion and centre the overall pan.
  2. Or choose Jump → Reset Pan Lab: it resets immediately, closes Jump and takes you to Pan Lab so you can inspect the controls.
  3. Playback, other effects and layer settings remain unchanged. The reset persists after reload; it is not Reset Patch or Panic.
  4. For song work, reset before saving your parts. Previously saved parts and frozen renders do not change just because you reset the live patch: Recall, reset, Amend/Save Amendment, and re-arm any part that needs the cleaner setting.

This is a mix recommendation, not a claim that every use of stereo motion damages audio. Keep a controlled amount when it helps the arrangement, and compare with Reset Pan Lab before committing a render.

Bastardloop Q — piano / string ensemble chords

Sample Length / Sample Decay: both sliders are on Q's main card and in the editor's Chord playback settings. Length trims each triggered sample's sounding window; lower Decay fades it earlier, useful for busy chord or arp patterns. Both range from 5–100%. At 100% the original envelope is retained, including for older patches and parts without these controls. They affect Piano, Strings, grid playback, ratchets and auditions without changing the notes, BPM or transport origin. Reverb and delay tails remain governed by their own mixes. Settings are saved in patches and Song parts; shortened samples require a length/decay-aware Song freeze. Recall, amend and re-arm older parts if you want them to use new shorter settings.

Copy Arp → X / L: choose ARP playback in Q and press Copy Arp on its card or in Chord playback. This copies the entire active Q pattern from step 1 to its end, not just the chord at the editing cursor. A 64-step Q pattern includes all 64 source cells, every chord change, the current order, voicing, transpose, once/repeat behavior, gaps and accents. Empty patterns copy silence rather than the builder chord. The status shows the source length and total copied arp pulses; faster/slower arp divisions can produce more/fewer pulses than source cells. Copy is disabled in block chord mode. In X or L, select a destination step and press Paste from Arp on the card or in the sequencer. Each pulse occupies one destination step, using that loop's existing rate, sound and effects. To paste a full 64-pulse copy into a 64-step destination, start at step 1. Only those cells are replaced; paste stops at the pattern end without wrapping and reports any omitted pulses. The copied pattern can be reused in both loops and is not changed by later edits in Q. Copy again to refresh it. The clipboard is temporary, but pasted notes, rests and accents are ordinary X/L sequence data and are embedded by Song New Part / Save Amendment, so recall on a new device does not require the clipboard.

Choose Q sound → Piano or Strings on the scarlet Q card, or in the editor's collapsed Key & chord roots settings. Piano is the original Salamander grand from SAMPLES_Q, with 30 sampled pitches across A0–C8 and four velocity layers. Strings uses recorded VSCO 2 CE cello, viola and violin sections from SAMPLES_Q_STRINGS, mapped across 17 roots with two dynamic layers and crossfaded sustain loops. The native string recordings cover C2–D6; notes outside that range are pitch-shifted. Both instruments load only the notes needed and use local files, not Dropbox or an external audio CDN.

Changing sound keeps the sequence and effect settings, stops the old instrument's voices and clears its sample bank. If Q is running it resumes on the existing clock once the new samples are ready; other layers do not restart. Strings sustain for the programmed gate, including held/tied chords. The instrument selector stays inside the existing collapsed editor settings and adds no row to the compact grid toolbar.

  1. Open Edit Sequence. The playable chord palette sits directly above the compact grid; Practice, Step/Live Record, Rest, Delete, Left 1/Right 1, Chord −/+, green All Play and red All Stop remain in one compact top row. On narrow phones, Practice and Chord −/+ use the short labels Prac and Ch −/+ without changing their functions. Expand Key & chord roots to choose the scale tonic, one of 85 named scales/modes, octave, inversion and voicing together. Custom lets you select any twelve-tone pitch set; the tonic stays included. These are twelve-tone equal-tempered scales, not microtonal tunings.
  2. The palette includes every supported chord whose notes fit the current scale: C major has 71 choices with the default octave and voicing. Filter by triads/suspended, four-note or extended chords if desired. Root focus puts that scale degree's chords first; it does not change the key. Changing inversion or voicing changes the displayed and played notes. Playing chords and individual sounding notes light up.
  3. Practice plays chords without writing. The dual-function Record button first arms Step; tap it again to switch to Live, then again to return to Step. A note underneath explains both functions. Step writes each palette tap at the edit cursor and advances. Live records each tap into the currently sounding grid step, using Q's audio clock and grid rate, not the edit cursor; it does not advance manually or restart the pattern. Recording wraps and overdubs, replacing only the tapped step. Tap timing is captured before piano loading. Live can start with an empty grid; arm Live then press green All Play. While stopped, Live auditions but never falls back to step entry. Practice disarms both modes.
  4. Rest writes silence at the live playhead in Live mode; otherwise it writes at the edit cursor and advances, including in Practice. It stops the audition. Delete clears only the selected cell without advancing. Tap an occupied grid cell to select and hear its chord, without recording or advancing; tapping an empty cell or Rest stops the audition. Copy/section marking stays silent. Green All Play starts/restarts the whole enabled pattern, Bastardloops and programmed drums on the existing shared transport; it respects layer enable/mute/solo and main-loop settings. Red All Stop stops every transport and Q audition. Q-only Play/Stop remain in Step editing.
  5. Left 1 / Right 1 move the selected grid chord by one cell to correct a live-recorded placement. On the narrowest phones they display as ← 1 / 1 →. Immediately after recording, the latest recorded chord is selected; otherwise tap its grid cell first. The selection follows the moved chord for repeated nudges. Moves wrap at the active pattern boundaries. An occupied neighbour, including a Rest, swaps places with the chord so neither step is lost. Notes, velocity, gate, ratchet, accent and tie stay with each step. Empty/Rest selections disable nudge. While playing, scheduling updates without restarting the shared clock; a chord moved behind the playhead is heard on the next pass. The current audition stops when nudging, but transport continues.
  6. Chord − / Chord + in the compact top control row transpose only the selected grid chord by one semitone and audition the result. They do not change other cells, the key, or whole-sequence transpose, and do not advance the cursor. Empty cells and Rests disable these controls; out-of-range changes are rejected. Seq − / Seq + remain available in Step editing for the complete sequence or marked section.
  7. Expand Step editing, transpose & chord builder for manual or out-of-scale harmonies, then use Audition Chord or Insert Chord. Select an existing step and use Audition Step to hear it. Major/minor, suspended, diminished, augmented, sixths, sevenths, ninths, elevenths, thirteenths and altered dominants are available.
  8. Back/Forward, Clear Step/All, Accent, ratchets and Rate −/+ work on the chord sequence. Length is measured in sequencer steps. Tie (Slide) sustains the same adjacent chord rather than applying a synthesizer pitch glide to a piano sample.
  9. Seq −/+ transposes the sequence by semitones. For a section, press Mark Trans, tap its first and last steps, then transpose. Clear Mark returns to whole-sequence editing. Out-of-range notes are rejected rather than silently folded into another octave.
  10. Copy selects a first/last step and overwrites at the chosen destination. Copy Sec repeats the selected section through the destination tail, matching L/X. Export MIDI includes every chord note and the saved tempo.
  11. Play Grid stops other playback and plays Q from step one. Stop also cancels any practice arpeggio. Start Bastardloops uses the shared clock; Stop All/Panic also stops Q. Q has its own volume, mixer channel, mute/solo, highpass, lowpass, room reverb and tempo-synced delay.
  12. Chord playback switches between polyphonic block chords and an arpeggiator. Orders are Up, Down, Updown (without doubled endpoints), Odds (odd note positions first, then even positions) and Evens (the reverse priority); every chord note is retained. One cycle lets each grid chord finish its order even when the next cell contains another chord; overlapping arpeggios keep their independent notes. An explicit Rest or pattern restart interrupts unfinished cycles. Until next chord repeats through empty cells until a new chord or explicit Rest. If chords occupy adjacent cells, choose a faster arp division or slower grid rate to hear more notes before that handover. A new practice chord replaces the preceding practice arpeggio.
  13. Chord playback settings collapse by default to leave more room for the chord palette and editing grid. Expand the summary to change block/ARP playback, order, repeat or timing; collapsing the menu does not reset those settings. Arp time — separate from grid sets the pulse division against shared BPM independently of the grid rate, from whole notes to 1/128, including triplets. The displayed divider/multiplier is relative to a sixteenth note. Step ratchets retrigger the chord/arpeggio at their own subdivisions. MIDI export follows the saved block or arpeggiated playback.

Accent on empty cells: select any grid cell, expand Editing Tools and tap Accent. An empty cell displays — !; it neither adds notes nor stops or restarts the hanging chord/arpeggio. The accent boosts all Q notes sounding during that grid cell, including notes started earlier. Accent Amount now controls actual audio gain independently of the MIDI velocity ceiling: 25% adds about 3.5 dB, 50% adds about 6 dB and 100% adds about 9.5 dB. The slider displays that boost in dB. At zero there is no boost. Leave mixer headroom; accents do not bypass Q's volume, effects or the main compressor. Clearing the cell removes its accent.

Custom Arp / Repository: open this popup from the Q card, or Build / Load Custom Arp inside Chord playback. Choose 1–32 pulses. Each column plays the selected chord-note rank, ordered from the lowest pitch; ranks 1–8 wrap to the number of notes in the current chord. The Gap row skips that pulse without shortening the rhythm. Tap a selected note again to turn it into a gap. Choose the independent arp division and One cycle or Until next chord / rest, then press Apply to Q. The shorter custom-arp release keeps notes from bleeding into dry gaps; reverb and delay tails may continue naturally.

Global arp repository: give the pattern a name and press Save new to server. This stores its exact note order, gaps, pulse division and repeat mode on the server, shared by MYGRAIN devices without browser storage. Existing names cannot be overwritten. Refresh fetches the latest library; Load selected brings a preset into the editable grid, then Apply to Q activates it. Closing without applying leaves Q unchanged. Saving a preset does not apply it automatically. Song New Part / Save Amendment embed the applied pattern itself, not just a repository reference. Version-six Q freezes include the corrected accents and custom gaps; re-arm older accented Q parts to rebuild their audio. Older unaccented Q freezes remain reusable.

Delay time offers straight, dotted and triplet choices for every division from 1/32 to one bar. Dotted times are 1.5 times the straight duration; triplets are two-thirds. Timing follows shared BPM, up to the existing 11-second delay limit. Q's room impulse is gain-normalised and its wet return is restrained, so adding reverb no longer applies the old excessive amplification. The dry piano path is unchanged; stacked chords, feedback and the overall mix still need headroom.

Check Gain Staging includes Q's level, reverb, delay and feedback controls with a piano/effects-path graph. Q and M+ have live mixer VU meters tapped after their own effects, including pan; M+'s existing input, compressor, delay, chorus and reverb audit checks remain available.

Song New Part and Save Amendment embed the exact samples needed by the complete saved Q sequence, plus the selected instrument, string sustain points and all chord, arpeggiator and effect settings, including dotted/triplet delay times. Recall restores that embedded bank, not another phone's cache or the source repository. String parts require a strings-aware freeze marker; an older piano-only renderer cannot silently substitute piano. Wet piano parts require the corrected effects-freeze marker; Arm Cache rebuilds older wet freezes using the quieter reverb while retaining the saved notes, samples and effect controls. Dry block-chord and arpeggiator freezes keep their existing compatibility. Existing Q parts without an instrument setting remain Piano, those without arpeggiator settings remain block chords, and older parts without Q load with Q off. The existing Song freeze rule still applies: it captures one global pattern and repeats that audio; it does not extend a freeze to cover a slower independent sequence cycle.
