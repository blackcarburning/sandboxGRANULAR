MYGRAIN Manual

MYGRAIN is a keyboard-first granular instrument for generated loops, recorded or loaded samples, BPM-locked modulation, filters, and quick mobile performance.

Quick Start

  1. Tap START MYGRAIN to unlock the browser audio engine.
  2. Tap Generate Loop for a full patch and sequencer pattern, or Generate Sample for a new generated sample while keeping the current pattern.
  3. Play the on-screen keyboard. Use Hold for drones and Panic if anything keeps sounding.
  4. Shape the sound with Sample Vol, Sample Solo, filters, LFO routing, and the LFO rate radio buttons.
  5. Use Export WAV for audio, Export JSON for patch settings, and Import JSON to load a saved patch.

Main Layout

The app is arranged around immediate performance. The keyboard stays prominent, while the performance panel gives fast access to generation, source balance, filters, LFOs, export, and safety controls.

AreaPurpose
Performance controlsMain sound and transport controls such as BPM, Generate Loop, Generate Sample, Play Loop, Sample Vol, Sample Solo, filter controls, LFO routing, and exports.
Source panelGenerated loop waveform, mic waveform, source loading, normalization, audition, and loop start/end ranges.
KeyboardTouch-playable note surface. Notes trigger granular playback and oscillator voices through the current patch.
TabsDeeper grain, filter, noise, FX, LFO, stereo, utility, oscillator, and sequencer controls.

Sources and Samples

Generate Loop

Generate Loop creates a complete loop-ready patch: source audio, sequencer pattern, and related randomization. The generated source is designed to stay locked to the project BPM.

Generate Sample

Generate Sample creates another generated sample without replacing the current sequencer pattern. Its timing is constrained to quarter, half, and whole-beat positions, with more low-frequency noise and less high-pitched content.

Low Noise Source

Low Noise Source biases generation toward lower-frequency, less bright material. This is useful when the generated source is too sharp or busy.

Record Mic and Load Audio

Record Mic captures microphone input after permission is granted. Load Audio imports an audio file from the device. Loaded and recorded audio can be used as granular sources and trimmed with the waveform start/end controls.

Loop Start and End

The generated and mic waveform panels each have start/end sliders. These define the region used by direct looping and granular playback. The loop end point can be controlled by LFO 1 or LFO 2.

Playing and Looping

Tap or drag on the keyboard to play notes. The granular engine reads from the active source loop, while oscillators can be blended in with the source controls.

  • Hold keeps notes sounding after you lift your finger.
  • Play Loop starts or stops the sequencer loop.
  • Osc On / Osc Off enables or disables oscillator contribution.
  • Noise Off clears active generated noise sources when noise is present.
  • Panic stops held notes and active voices.

Filters and LFO Routing

The low-pass and high-pass filters sit on the main sound path. Use cutoff and resonance controls to shape the tone, then route LFO 1 or LFO 2 to each target.

  • LP Cutoff / LP Res shape the high-frequency rolloff and low-pass resonance.
  • HP Cutoff / HP Res remove low frequencies and set high-pass resonance.
  • LP Cutoff LFO, LP Res LFO, HP Cutoff LFO, HP Res LFO each provide L1 and L2 buttons for modulation routing.
  • LFO 1 Filter Depth and LFO 2 Filter Depth set how strongly each LFO affects routed filter targets.
  • LP Filter and HP Filter let you turn each filter on and choose 2-pole or 4-pole behavior.
  • Filter In and Filter Out trim gain before and after the filter chain.

LFO Rate Controls

MYGRAIN uses BPM-locked LFO rates. The main page includes radio buttons for LFO 1 and LFO 2 with straight, dotted, and triplet values.

Radio labelMeaning
1/4, 1/2, 1x, 2x, 4xStraight divisions and multipliers relative to the shared BPM clock.
DDotted timing: one and a half times the straight value.
TTriplet timing: two thirds of the straight value.

The global BPM control preserves the selected LFO 1 and LFO 2 timing ratios when BPM changes.

Recording, WAV Export, and JSON Export

Record Output

Use Record Output to capture live performance. Arm waits for a keyboard press before starting, which is useful for cleaner takes.

Export WAV

Export WAV renders DAW-ready audio for the selected bar count. When generated audio exists, MYGRAIN can also export a generated dry stem.

Export JSON and Import JSON

Export JSON saves the patch settings as a preset file. It stores sliders, selects, LFO routing, filter states, performance modes, and metadata about whether samples were present.

Import JSON loads one of those patch files through the same preset validation path as the Utility tab's Load Preset button.

Audio samples are not embedded in patch JSON. JSON is good for patch settings; WAV or Save Audio is the right format for actual sound.

Preset and Sample Saving

Save Preset and Export JSON save settings only. If a patch used generated, recorded, or loaded audio, the JSON marks that a sample reload may be required.

Save Audio exports the current sample as audio. Load Preset imports JSON settings. Load Audio imports audio separately.

iPhone Notes

  • Always tap START MYGRAIN before generating, recording, playing, or exporting audio.
  • If a slider feels hard to grab, use a deliberate horizontal drag from the thumb area.
  • Use the browser share sheet when saving JSON or WAV files.
  • If audio stops after switching apps or locking the phone, return to MYGRAIN and use Reset Engine if needed.
  • Large audio files are intentionally limited for mobile stability.

Troubleshooting

ProblemTry this
No soundTap START MYGRAIN, raise Master Trim, check Sample Vol, turn off FX mute, and press Panic before trying again.
Generated sample is too brightEnable Low Noise Source, lower LP Cutoff, reduce LP Res, or use Sample Solo to hear the source clearly before mixing.
Loop feels too randomUse Generate Sample again; current generation favors quarter, half, and whole-beat timing. Reduce Gen Swing if needed.
Preset loads but sounds differentReload the original sample or generate a new one. Patch JSON does not embed audio.
Stuck note or runaway soundTap Panic. If needed, use Reset Engine.
Export does not appearCheck the browser download/share sheet. On iPhone, files may appear through the share workflow rather than a desktop-style download bar.
