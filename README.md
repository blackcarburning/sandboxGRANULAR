# sandboxGRANULAR
Web based granular synth

Randomize now builds loop-ready patches with weighted rhythmic archetypes (straight, pulsed, syncopated, sparse, rolling, glitch/fill), repeated motifs with controlled mutations, bounded cross-mod routing, and conservative gain-friendly macro correlation.
For reproducible development/debugging, rhythmic blueprint generation is deterministic when a seed is provided to the helper path.
