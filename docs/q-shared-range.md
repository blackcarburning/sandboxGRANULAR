# Q whole-pattern audition range — 20261024-q-shared-range-1

Loop Set / From / To arm an inclusive, temporary Q range. Start in **All loops** repeats that same musical time window across all enabled cards, sampled loops, K tracks, L/X, drums and the main sequencer. Existing independent timing divisions are retained: each lane maps the selected time window to its own grid. Audio loop regions are copied/cropped in memory; saved patterns and source buffers are not shortened or rewritten. Q Solo still plays only Q. Stop retains endpoints but disposes the active shared section; Loop Off restores full-pattern playback. Closing Q clears its temporary range. Global Restart also respects the armed Q section. Tempo/Q rate changes rebuild the section against the new clock.

This uses the existing MygrainPatternSection section engine, previously used by the individual-chord editor. Ownership distinguishes the main Q range from the editor's preview. Q starts at the section origin, while accompanying sources resolve their correct original pattern offset. Returning from the chord editor resumes the main shared section if it was playing; explicit Stop cancels that resume.

A successful individual-note/chord edit marks its sequence cell `customChord:true` and adds the exact edited voicing to the account/browser-local green holding library. Existing exact voicings are deduplicated. No-change edits do not add entries. Undo restores the previous sequence chord; a saved holding entry remains until explicitly deleted. A local storage failure is reported without losing the edited sequence chord. Existing Song validation already supports this optional marker; no schema bump or data rewrite is required. The holding library remains browser-local; recorded green chords are portable in songs/patches.

Native candidate tiles show only the chord name. Holding tiles show a compact name and Custom label, with Delete below. Sequence cells have a separate step number and simple chord name, rectangular 80px-minimum by 50px cells; the grid scrolls horizontally on narrow screens. Selected Chord + / − are direct right-rail actions immediately below Rest. These selected-chord controls are distinct from left-rail marked-sequence transpose and candidate pitch controls.
