# Effect preset navigation and Mutilator power — PRESET.1

The nine effect cards were audited. Bass Face, Filter Playground, WireWorld, Sonic Crystal and Bubble Chamber have factory-menu +/- navigation. Wasp has direct preset buttons, Mutilator a strain selector, Turntable direct controls, and Resonator object/band selectors; those four do not have a navigable factory bank.

Each bank now retains its last matched factory ID separately from the dropdown label. An edited sound still displays Custom. Previous/Next fall back to the retained ID, follow the actual grouped menu order and wrap at the ends. Each acoustic bank owns an independent cursor. Matching restored sounds (including Undo/Redo) update the cursor; nonmatching edits do not erase it. The cursor is page-local UI state, not part of sound settings or Song identity. No factory recipes, IDs, schemas, audio parameters or outputs changed.

Mutilator power is no longer cleared by D Off or restoring a D-Off snapshot. Its power and rhythm controls are enabled without a loaded/active D card. Manual Mutate uses configureOnly, as Bass Face does, so it can prepare a sound while its source is silent. Its history label is a strain edit, matching Bass Face, so generic generation cleanup does not immediately disarm it or reset unrelated processing. Batch/random-patch eligibility still checks active inputs. Existing zero amount/mix behavior is unchanged. Native D source scheduling, D level and mute remain authoritative for D audio: armed Mutilator does not turn on D or create sound from an inactive source. Alternate input routing remains independent of D. Saved settings keep the existing modes.loopD.mutilator schema.

Server Song, isolated decks and WAV exports use the same loop-d.js restore and routing code. No renderer version bump is necessary: previously renderable D-on and alternate-input states keep identical processing; newly retainable D-off/native-input armed states remain silent. No source ZIP, render identity, revision or cache marker migration is needed.

Regression coverage: tests/effect-preset-continuity-browser.cjs exercises all five menus in Chromium/WebKit desktop/phone, Custom continuation in both directions, manual reselection, both end boundaries, undo/redo, independent cursors, nine-effect inventory, Mutilator power/rhythm/Mutate, D cycling, portable ZIP and local reload. tests/mutilator-independent-song-browser.cjs runs real isolated server jobs for native D levels, main following, D-off armed silence, D-off alternate-input wet, bypass and a genuine pre-Mutilator native D archive; also WAV, phone PCM playback, source/revision stability and warm reuse. Existing tests/effect-output-browser.cjs checks final audible PCM and linked outputs for all nine effects in both browser engines and viewport classes.
