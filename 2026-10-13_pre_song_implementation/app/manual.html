MYGRAIN Manual

A practical operator manual for MYGRAIN: the browser-based granular instrument, loop generator, Bastardloop workstation, drum sequencer, sample browser, mixer, effects chain, and export hub.

Manual revision: 2026-10-11. Covers the current performance layout, Loop L, Loop X, WAV Browser, patch ZIP workflow, jump drawer, layer switches, and mobile operation.

Quick Start

  1. Tap START MYGRAIN. Browser audio is locked until this gesture; microphone permission is only requested when you use Record Mic.
  2. Set BPM and Pattern Length. BPM controls musical timing across the app; Pattern Length controls sequencer-style grids.
  3. Create or load sound with Generate Source, Low Noise Source, Record Mic, Load Demo, Load Audio, grain sample browsers, Bastardloops, Dropbox Sample Layer, or the Drum Machine.
  4. Play from Keys. Use Hold for drones, Arp for clocked held-note playback, and Octave to move the keyboard range.
  5. Build rhythm or texture with Generate Loop, Start Bastardloops, Start Drums, or Dropbox Sample Layer.
  6. Balance layers in Layer Switches and Mixer. If a layer is silent, check both its switch and its level.
  7. Use Export WAV, Export Final Mix to Repo, Export Stems, or Export Patch ZIP when the patch is worth keeping.
Mobile habit: on iPhone, use the right-side Jump drawer instead of long scrolling. It goes directly to Keys, loops, Drums, Layer Switch, Mixer, Quick Grain, Actions, Export, WAV Browser, Stem Export, Grain, Mix, LFO, FX, Sources, Waveforms, and Pan Lab.

What MYGRAIN Is

MYGRAIN is best understood as a performance mixer wrapped around several sound makers. The playable center is a three-layer granular instrument plus oscillator. Around that are generated loops, one-shot sample sequencers, Dropbox sample playback, a drum machine, filters, shared effects, recording, and repository export tools.

Signal Flow

Sources feed instruments and loop layers; the mixer feeds the filter/effects/output path.

Performance Order

The app is arranged so performance controls appear before deep editors.

Navigation and Layout

The app has three main ways around: normal scrolling, the right-edge Jump drawer, and direct buttons that open popups such as Synth, Drum Machine, Patch Browser, WAV Browser, Stem Browser, and sample browsers.

Starting and Audio Safety

Browsers require a user gesture before sound can start. START MYGRAIN creates or resumes the Web Audio engine, unlocks the audio graph, and shows the app.

  • Start MYGRAIN unlocks audio. If a button says to start first, tap this before retrying.
  • Panic stops held voices, stuck notes, and active transport state without resetting the patch.
  • Reset Engine rebuilds the audio graph when browser audio is in a bad state.
  • Stop All stops active app transports; Restart All restarts tracked clocked layers together.
  • Microphone access is separate. MYGRAIN does not ask for the mic until Record Mic is used.

BPM, Pattern Length, and Timing

Set BPM is the shared musical clock. It affects generated loop timing, arpeggiator rate, sequencer grids, Bastardloop transport, Drum Machine transport, LFO multipliers, delay divisions, and render/export timing.

Pattern LengthSets the length for step-based pattern work. The visible default is 16 steps, with longer patterns available.
Export BarsSets the render length for WAV export. This is separate from Pattern Length.
Restart AllUse after timing changes when you want active loop layers to realign from a fresh origin.

Sources and Waveforms

Sources are audio buffers that MYGRAIN can play, granulate, trim, audition, export, or resample. They stay separate so a mic take, generated loop, loaded audio file, output capture, and grain sample do not overwrite each other by accident.

SourceHow to fill itWhat to do with it
Generated LoopGenerate Loop or generated-source actions.Play as a dry loop, send into granular layers, trim, transpose, and mix.
Main Grain SampleBrowse sample folders or route another source.Primary playable granular material.
Mic RecordingRecord Mic.Trim, normalize, preserve duration, and use as a granular source.
Grain A Mic / SampleRecord, browse sample folders, or switch between Mic and Sample.Secondary granular layer with its own tune, envelope, width, smoothing, and mute/solo.
Grain B Mic / SampleRecord, browse sample folders, or switch between Mic and Sample.Third granular layer, often useful for low or wide supporting material.
Output SourceRecord MYGRAIN back into itself.Resample the full patch and use the result as new material.
  • Trim to Selection commits the current waveform start/end selection into that source.
  • Audition lets you hear a waveform source before committing it to a layer.
  • Preserve Duration keeps playback length stable when pitch changes; turn it off for sampler-style speed/pitch changes.
  • Normalize raises source level when available; use it before detailed mixing if the source was quiet.
  • Clear, Clear Sample, and Clear Mic remove a buffer from that slot.

Granular Layers

The granular instrument has three performance layers: Main Grain, Grain A, and Grain B. Each can use different source material and tuning while sharing the app-wide mixer and FX chain.

Main GrainBase playable layer. Commonly use it for the central sample or mic recording.
Grain ASecondary layer. Good for a higher interval, alternate source, or wider texture.
Grain BThird layer. Good for bass, octave support, or a contrasting grain size.

Important controls include Source, Start Point, Grain Size, Coarse Tune, Fine Tune, Attack, Decay, Release, Blend, Smoothing, Stereo Width, Volume, and Solo. The Quick Grain card brings the most-used tuning, width, smoothing, and LFO depth controls into the performance area.

Generated Loop and Dry Loop

Generate Loop creates a BPM-aware loop that can run as its own dry layer and also feed the grain engine. Loop Play and Loop Stop control that loop transport. Loop Level, Dry Trim, and the Loop On layer switch control how much of it reaches the mix.

  • Gen Swing changes generated-loop timing feel.
  • Loop Transpose transposes generated-loop playback by octaves.
  • Gen Loop Mix controls the generated-loop contribution.
  • Dry Filter Off bypasses or enables filter treatment for the dry loop path.

Bastardloops A/B/C/V/P/O/L/X

Bastardloops are sample-backed loop layers that can run beside the keyboard, generated loop, Dropbox sample, and drums. All Bastardloop layers use the shared Bastardloop transport unless a layer has its own card-specific start button.

The note-size checkboxes choose the rhythmic material allowed into generated Bastardloops. Smaller divisions produce busier loops; larger divisions produce longer hits. Uncut keeps longer sample slices intact. Don't Preserve Duration makes pitch behave like sampler speed.

Loop L and Loop X Sequencers

Bastardloop L plays one-shot leads from SAMPLES_LEADS. Bastardloop X plays one-shot bass samples from SAMPLES_BASS. They are not random sliced loops like A/B/C/V/P/O; they are synced note sequencers.

Dropbox Sample Layer

The Dropbox Sample Layer loads one sample from SAMPLEDROP, SAMPLEDROP_2, or SPLICE_CLAW and plays it as its own loop layer.

  • Browse Samples opens the browser for manual choice.
  • Load Random Sample picks a random sample from the selected source family.
  • Stretch To Loop stretches the sample to fit the Bastardloop bar. Off means the sample is dropped at the start of each bar.
  • Dropbox Semitone and Dropbox Fine Tune tune playback.
  • Preserve Duration keeps length stable while tuning. Turn it off for classic sampler speed/pitch behavior.
  • Solo Off/On isolates the Dropbox sample layer for checking.
  • Dropbox Sample On/Off in Layer Switches mutes or enables this layer without changing its settings.

Layer Switches and Mixer

Layer Switches are quick mutes. Module Mixer is level balance. Use both: a layer can be on but turned down, or loud but muted by a switch.

Quick mutesOsc, Granular, Sample/Drums, Loop, Bastardloop A/B/C/V/P/O/L/X, Dropbox Sample, and Drum Machine.
Module levelsOsc, Sample, Loop, Noise, Dropbox Sample, Drum Machine, every Bastardloop, Main Grain, Grain A, Grain B, and Grain Amp.
Output VUUse the meter to catch silent patches and hot output before exporting.

For troubleshooting silence, check in this order: Start MYGRAIN, Panic, Layer Switches, Module Mixer, source buffer, then filter/FX mute.

Internal Effects

The Internal Effects section contains shared delay, shared reverb, and advanced final-bus shaping. The top action buttons expose common toggles such as FX On, Reverb Off, FX Post Filter, and FX LFO Off.

DelayTempo-synced echo with feedback, tone shaping, and width-style timing.
ReverbRoom, hall, cathedral, cloud-like spaces, shimmer shift, room tone, and wet mix.
Advanced busDrive, crush, fold, compression, sidechain, pan/motion, and placement controls.
High feedback, shimmer, drive, and reverb settings can get large quickly. Use Master Trim, Mixer levels, FX Mute, or Panic if the output gets away from you.

Useful Workflows

Fast playable patchStart MYGRAIN, Generate Source, open Keys, adjust Main Grain tune/size, set Hold or Arp, then balance with Mixer.
Loop bed plus keyboardGenerate Loop, Loop Play, add Bastardloop A or B, then keep the keyboard on top with Layer Switches and Master Trim.
Lead and bass sequenceChoose Lead Sample for L, Choose Bass Sample for X, Edit Sequence on each, double tap steps for ratchets, then Start Bastardloops.
Sample loop layerOpen Dropbox Sample Layer, choose source family, Load Random Sample or Browse Samples, choose Stretch To Loop, tune, then balance Dropbox Sample level.
Resample MYGRAIN into itselfRecord Output Source, jump to Waveforms, trim Output Source, then select it as a grain source for further processing.
DAW handoffSet Export Bars, export a final WAV, then Export Stems with notes. Export Patch ZIP as a restore point.

Troubleshooting

ProblemTry this
No sound at allTap Start MYGRAIN, press Panic, check Master Trim and Output VU, then Reset Engine.
One layer is missingCheck Layer Switches, Module Mixer, that layer's own level, and whether the source/sample is loaded.
Dropbox sample will not muteUse Layer Switches and confirm the button reads Dropbox Sample Off. If it flips back on, report it with Debug Console output.
Loop L or X is silentChoose the Lead/Bass sample, check the sequence has notes not only rests, verify Bastardloop L/X On in Layer Switches, then check Mixer level.
Step ratchet will not armOpen Edit Sequence and double tap the same step. The status should report ratchet edit for that step.
Drums are too quiet after randomizationCheck Drum Machine level, Drum Machine On, Direct Out, delay/reverb sends, and Master Trim.
Pitch feels wrongCheck keyboard Octave, Loop Transpose, source tune, grain coarse/fine tune, Bastardloop semitone/fine tune, and Preserve Duration state separately.
Timing feels out of phaseUse Restart All after changing BPM, Pattern Length, or layer start state.
Export is too long or shortCheck Export Bars. Pattern Length and Export Bars are separate.
iPhone is stuck on old behaviorReload the public route, check the visible build badge, and recreate any stale home-screen shortcut if needed.
Something breaksTap Copy Debug in the Debug Console and send that text with what you touched immediately before the problem.

Working habit: solo or mute aggressively while tuning. Fix one layer, bring the mix back, then save a Patch ZIP before the next risky change.
